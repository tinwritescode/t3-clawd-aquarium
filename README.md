# T3 Clawd Aquarium

A remix of [rohit3a/t3-clawd](https://github.com/rohit3a/t3-clawd), the Claude-inspired theme for T3 Code, with a pixel aquarium behind the chat.

One theme file. Uses 19.9k of T3 Code's 20k-character CSS limit.

## Changes from T3 Clawd

- Pixel aquarium in the conversation area: 12 fish in two schools (clay and blue) swimming in opposite directions over a seabed of seaweed, coral, rocks, a shell and bubbles. Motion stops under `prefers-reduced-motion`.
- Header keeps "T3 Code", with "Code" in a clay gradient.
- Quiet "New chat" row instead of the big clay button. ⌘N shows on hover.
- Sidebar rows in the style of Claude's list: single line, 36px, no empty slot on the right.
- Search bar and top menu with more breathing room.
- Darker row hover and selected colors.

## Install

1. Download [`t3-clawd.json`](t3-clawd.json).
2. In T3 Code, open **Settings → Appearance** and click **Add a theme**.
3. Drop the file in (or paste its contents into **Theme JSON**), then pick **T3 Clawd**.
